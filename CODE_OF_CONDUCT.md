# Code of conduct

Keep project discussions welcoming, respectful, and focused on the work.

- Discuss ideas and evidence without personal attacks.
- Make room for different backgrounds, experience levels, and perspectives.
- Avoid harassment, discrimination, threats, and unwanted personal contact.
- Respect privacy. Do not publish someone else's personal information or any
  real patient information.
- Give constructive feedback and acknowledge corrections.

These expectations apply to project issues, pull requests, discussions, and
other spaces maintained for the project. Maintainers may remove harmful content,
close disruptive discussions, or restrict participation when needed.

For a concern requiring confidentiality, use a private channel explicitly
published by a maintainer or available through the repository host. If no private
channel is available, request one without posting sensitive details.
